# Jarvis AI Chatbot

A ChatGPT-like conversational AI web app powered by OpenAI's GPT-3.5 Turbo model.  
Built with a **React frontend** and **Express.js proxy server**, and deployed on **Vercel** (frontend) and **Render** (backend).

---

## 🚀 Key Features

- **Interactive Chat Interface**  
  Real-time user–AI conversations powered by OpenAI's GPT-3.5 Turbo API.

- **Responsive React Frontend**  
  Seamless user experience with input state handling and dynamic response rendering.

- **Secure Express.js Proxy Server**  
  Handles API requests with middleware for error handling and rate-limiting.

---

## 🛠️ Technical Skills

- **Frontend:** React (component-based UI, hooks for state management).  
- **Backend:** Express.js (REST API, middleware integration with OpenAI).  
- **AI Integration:** OpenAI GPT-3.5 Turbo API for natural language processing.  
- **Deployment:** Vercel (frontend CI/CD), Render (backend hosting).  
- **Tools:** Git & GitHub for version control, npm for package management.
